## What the project is

SME DRHP drafting system (capstone Track A): QLoRA fine-tune of **Qwen2.5-7B-Instruct** (student) on rows built from a
**Qwen3-32B-AWQ** teacher. Two skills: **drafting** (one sub-section from FACTS) and **extraction** (typed facts as
JSON). Prompt formats are in `data/prompts.py` and are shared by training and the app.

Data: 1,446 train rows (657 drafting) and 139 test rows (89 drafting) in `trainset/out/`.

## Colab notebook (`colab/sme_drhp_colab.ipynb`, generated by `colab/make_notebook.py`)

Drive folder `My Drive/sme_drhp/`. L4 runtime for training and predictions. On every new machine: Stage 0 (cell 3),
vLLM install (cell 4), Unsloth install (cell 13), **Restart session**, Stage 0 again. Restart before every
predictions run (vLLM keeps the GPU memory).

| cell | does |
|---|---|
| 14 | RUNS: A, B, C, ablation1, seed2, seed3; set `RUN = '…'` before training or predicting |
| 15 | training (checkpoints in `runs/<RUN>/ckpt`, adapter in `runs/<RUN>/adapter`) |
| 16 | held-out loss on the test rows, adapter on and off: the yes/no measure for a configuration |
| 17 | vLLM predictions. `BASELINE = True` for the base model (B0); `TEMP = 0.3` samples drafts (extraction stays greedy) and writes `predictions_test_t03.jsonl`. Drafts are cut at a loop by `trim_repeats` |

Working versions: Unsloth 2026.10.11, Transformers 5.17.0, vLLM 0.32.0, Torch 2.11–2.13 (cu130).
