# Issuer bundles for the end-to-end test (H5)

Five issuer bundles, each 42 files an issuer hands to its lead manager: financial statements (digital and scanned),
Word resolutions and profiles, Excel workings, certificates, licences and quotations, with scanned pages, an image and
a flow chart. They are generated by `bundles/`, and the app is run on each one through its own API (`vm/h5_run.py`).

| Bundle | Company | Source |
|---|---|---|
| 1 | Ashtavira Flexipak Limited | `bundles/driver.py` run on the Ashtavira master data (`bundles/issuer.py`) |
| 2 to 5 | Kestrel, Bhuvanam, Tavanvi, Oakvale Flexipak Limited | the same generator, retargeted by `bundles/variants.py` |

## What is shared and what differs

- **Differs per company:** names, group company, CIN, GSTIN, PAN, IEC, UDYAM, directors' DINs and PANs, plot and shed
  numbers, bank, auditor, BRLM, legal counsel, research firm, and the people.
- **Shared across the four variants:** the sector, city, state, estate, the financial model and so the figures.
  Each bundle's figures tie across its own files, but the four variants carry identical financial numbers.
- **Licence numbers** are not retargeted, so the four variants share them.

This is a limitation of the test set: it tests formats, extraction, drafting and verification on five complete
bundles, but not five different financial profiles. Distinct issuer data would need a separate master dataset per
company.

## Regenerate

```bash
python bundles/variants.py                 # all four variants into bundles/out/
python bundles/driver.py <out_dir> <folder>  # bundle 1 from the Ashtavira master data
python bundles/check_leftovers.py bundles/out/<folder> Ashtavira Desai Bhatt Kalindi Arthaveda Meridian
```

`check_leftovers.py` searches the text of the built files for names of the source company; it should report only
the shared estate name ("Sanand").
